Сервис для работы с каталогом книг.

## Возможности

- Добавление книг
- Просмотр списка книг
- Поиск книги по ID
- Изменение информации о книге
- Удаление книги
- Пагинация списка книг

## API

- GET /api/catalog/products — список книг
- GET /api/catalog/products/{id} — получить книгу
- POST /api/catalog/products — добавить книгу
- PUT /api/catalog/products/{id} — изменить книгу
- DELETE /api/catalog/products/{id} — удалить книгу
